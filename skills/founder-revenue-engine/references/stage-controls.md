# Stage Controls

## ICP controls

A useful ICP names the role, company or project state, triggering event, urgent pain, current workaround, buying authority, and disqualifiers.

- Frequency alone is not buying intent. Weight urgency, action, spend, switching behavior, and direct requests more heavily.
- Preserve the market's language for later narrative work.
- Confidence reflects evidence quality and coverage, not enthusiasm.
- If a signal is older than the evidence window, label it stale or exclude it. If a signal has no source or date, do not treat it as evidence.
- If the profile is broad enough to include everyone, narrow it by pain, trigger, role, and company state.

## Market narrative controls

- Problem statements use the audience's observed language and context.
- The offer explains the change, mechanism, boundary, and reason to believe.
- Proof may be a verified result, demonstration, credential, process, or explicitly labeled pilot evidence.
- Objections are answered with evidence or an honest limit.
- The call to action matches the current commercial stage.
- If proof is absent, use an honest pilot or learning claim rather than invented results.
- If the audience and buyer differ, name both and adapt the call to action.
- Route any unsupported claim back to research or remove it.

## Outreach sequence controls

- Each message has one objective and one clear ask.
- Personalization comes from a named source, never inference presented as fact.
- Follow-ups add context or proof rather than repeating the first message.
- Stop rules cover reply, opt-out, invalid address, or sequence cap.
- If personalization data is missing, write a research placeholder rather than inventing a detail.
- If proof is weak, lower the ask to a learning conversation or pilot.
- If the sequence requires a connected account action (send, schedule, CRM write), report the required confirmation separately. Drafting authority never includes sending authority.
