# Brand context and authority

Use the current conversation, supplied assets and confirmed brand material. For an unnamed brand, work with the user's current brand and identify the evidence already available. Keep historical boards as examples unless the user confirms them as current. An explicitly named other brand is a valid target.

Separate **supplied facts**, **confirmed decisions**, **proposed directions** and **unresolved questions**. This skill may develop strategy; a proposed position is useful work, not an approved claim. Ask only about information whose absence materially changes the requested result. Proceed with labeled proposals for open creative choices.

This skill owns strategy, briefs, identity systems and review. Each phase returns a complete result independently. A brand name mentioned in an image-generation prompt does not trigger this skill. Transfer an ordinary brief or assets to another tool only when the user requests that collaboration. No external palette website or color tool is required.

Choose color from the brief and visual intent. Color-learning sources are optional alongside other references and free color exploration. Preserve named colors, values and roles when provided. If a named external palette is unavailable, keep supplied values and state which details remain unknown; do not invent a combination number or halt unrelated brand work.

The user makes final creative selections. Assistant findings, structural checks and proposed directions do not establish acceptance. Save a preferred direction or replace confirmed brand guidance only after explicit selection.
