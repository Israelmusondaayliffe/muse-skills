# Identity methods, visual catalogs and board presets

Load only the sections needed for the current identity deliverable. Strategy and logo methods apply broadly. The sparse board treatment and its output defaults apply only when that preset is chosen. Other visual directions, dense information systems and non-board deliverables are valid.

## Reference style DNA

The desired visual quality is inspired by premium brand-guidelines decks:

- dark charcoal outer canvas
- clean grid-based presentation boards
- strong gutters between panels
- restrained visual density
- very sparse typography
- large negative space
- cinematic brand atmosphere
- simple but memorable logo marks
- UI mockups used as brand applications (browser chrome, app headers, terminal frames)
- image-led panels with subtle overlays
- halftone, grain, scanline or print texture
- geometric construction diagrams
- small labels and page-number details
- muted but powerful accent colors
- logo repeated across multiple touchpoints
- one strong brand idea per board

The references are not a fixed style. They define the quality bar, restraint and presentation logic.

## Core principle

A premium brand kit is not decoration. It is a visual argument for why the brand exists. Every board must answer:

1. What does this brand represent?
2. What is the core metaphor?
3. How does the logo express that?
4. How does the system scale across UI, print, image and detail?
5. Why does the whole thing feel ownable?

## Default output

For the optional sparse overview preset:

- Describe one brand-kit overview image
- Default layout: `3 × 3`, aspect ratio `4:3` or `16:10`
- Clean presentation grid, consistent gutters, minimal text
- Every panel connected to the same brand idea

Allowed layouts: `3 × 3` full identity system · `2 × 3` cinematic deck · `2 × 2` compact concept board · `1 × 3` horizontal strip · `4 × 2` wide contact sheet · custom when requested.

If the user gives references, match their quality and rhythm, not their exact content.

## Brand strategy first

Use supplied or confirmed strategy first. When strategy is open, develop an explicitly proposed interpretation from the available evidence. Think through: category, audience, product function, emotional promise, cultural position, trust level, visual world, symbolic metaphor, what the brand should avoid. The visual system must be based on meaning.

| Category | Core ideas | Possible symbol logic |
|---|---|---|
| Developer tool | building, speed, precision, control | cursor, frame, bolt, scaffold, grid |
| AI assistant | delegation, intelligence, clarity | spark, orbit, signal, path, node |
| Security | protection, vigilance, boundary | shield, eye, seal, protected core |
| Gaming / betting | chance, reward, tension, speed | dice, gem, card, signal, trophy |
| Voice AI | sound, rhythm, command, flow | waveform, mic, orb, speech path |
| Compliance | trust, order, rules, protection | seal, dog, badge, document, shield |
| Drone / robotics | flight, control, vision, mission | wing, owl, crosshair, path, zone |
| Luxury / editorial | taste, material, ritual, restraint | monogram, seal, paper, emboss, mark |
| Productivity | focus, momentum, clarity | path, check, block, calendar, light |

Do not pick symbols randomly.

## Logo generation standard

The logo must be professional: simple, memorable, symbolic, scalable, ownable, visually balanced, connected to the brand idea, usable as icon, wordmark, badge, UI mark and pattern.

Avoid: generic lightning bolts unless strongly justified, random animals, fake luxury crests, copied famous marks, overcomplicated symbols, clipart-style icons, meaningless sparkles, inconsistent logo variants. The logo should feel like it came from research and reduction.

## Logo concept methods

Use one, or combine two maximum.

**1. Monogram + meaning.** Combine the brand initial with a metaphor (e.g. `K` + kite/frame/direction, `S` + sound wave). Do not make a boring letter icon; use negative space, cuts, folds or geometry.

**2. Product action.** Turn the product's main action into a symbol (build → frame/scaffold, protect → shield/boundary, speak → waveform/pulse, automate → loop/handoff). Make it abstract and premium, not literal.

**3. Metaphor fusion.** Combine two meaningful ideas into one reduced mark (owl + drone vision, shield + mountain, moon + waveform, dog + compliance seal). The fusion should be subtle and readable.

**4. Negative space.** Use empty space to create intelligence: hidden arrow, protected center, cutout initial, internal path, eye formed by crossing shapes. Negative space should be crisp.

**5. Construction geometry.** Build the mark from a clear system: circles, diagonal cuts, grids, frames, modular blocks, layered cards, orbital paths, crosshairs, measured linework. One panel can show the construction logic.

## Board composition DNA

A strong board feels like a curated sequence with rhythm: quiet, functional, emotional, technical, atmospheric, detailed. Use a large calm cover panel, one digital mockup panel, one image-led atmosphere panel, one system/construction panel, one physical or icon application panel, one quiet tagline panel. Do not make every panel equally loud.

### Default 3 × 3 panel system

1. Logo cover — large logo and wordmark, strong negative space
2. Logo construction — symbol breakdown, grid, geometry or negative-space logic
3. Digital application — browser chrome, app header, terminal, dashboard fragment or app icon
4. Brand essence — one short tagline, large readable type, sparse composition
5. Color system — swatches, gradient strips, discs, material chips or palette cards
6. Typography — large type specimen, alphabet row or type pairing
7. Physical application — card, folder, badge, poster, label, seal, packaging or object mockup
8. Image direction — cinematic landscape, product crop, halftone poster, editorial scene or material texture
9. System detail — UI chips, input bar, command line, icon row, badge system, component strip or pattern detail

### 2 × 3 cinematic layout

1. Logo / wordmark — centered or offset, extremely minimal
2. Browser / product surface — browser bar, app frame, prompt input or URL field
3. Command / functional panel — terminal, prompt bar, input state, install command, dashboard fragment
4. Atmosphere / campaign image — halftone landscape, cinematic image or art-directed photo
5. Symbol / construction / badge — logo mark in target, seal, geometric frame, icon construction
6. Tagline / system promise — one short line, large type, quiet background

## Visual modes

Choose based on the brand.

- **Dark developer / builder** (developer tools, coding agents, infra): near-black panels, monospace accents, command lines, terminal windows, subtle grid; cyan/blue/coral/lime accents. Logo logic: cursor + frame, bolt + build speed, scaffold + monogram. Mood: precise, sharp, confident.
- **Dark product / operator** (business, growth, sales tools): black/dark red/amber, glowing UI chips, card systems, segmented flows, icon rows. Logo logic: signal, path, loop, switch. Mood: fast, operational, tactical.
- **Dark nature / calm system** (strategy, travel, wellness, climate): deep green, lime accent, misty landscapes, soft overlays, dark editorial grid. Logo logic: path, leaf, moon, horizon, compass. Mood: calm, trustworthy, focused.
- **Dark security / threat intelligence**: black/navy, shield forms, radar lines, alert chips, controlled gradients. Logo logic: shield, raptor, eye, protected core. Mood: serious, vigilant.
- **Light editorial / compliance** (legal, privacy, trust): warm ivory, paper texture, small serif labels, seals/badges, deep blue/red/gold accents. Mood: trustworthy, refined, modern.
- **Luxury / beauty / fashion**: ivory/stone/espresso, serif wordmark, elegant monogram, paper grain, embossing, editorial crops, soft shadows. Mood: tasteful, expensive.
- **Voice / communication**: dark indigo, lilac glow, waveform, mic motif, app icon. Mood: fluid, intelligent, intimate.
- **Cultural / experimental** (music, creative tools, events, gaming): halftone, CRT texture, bold accent color, poster-style panels. Logo logic: custom wordmark, icon with attitude. Mood: memorable, controlled.

## Premium detail language

Small page numbers, tiny footer labels, alignment marks, construction lines, crosshair grids, thin rules, browser bars, rounded rectangles, image masks, soft shadows, low-opacity texture, halftone treatment, one highlighted word, one accent chip, one strong icon state. Use sparingly — detail should reward looking closer, not crowd the board.

## Text rules

For sparse boards use very little text; for guidelines use what the reader needs. Good: brand name, one tagline, one URL, one command, 2–5 section labels, short UI chips. Bad: long paragraphs, tiny fake body copy, lorem ipsum, dense explanations. Text must be large and sparse enough to render well.

Taglines should be short and specific ("Nothing random.", "Your network. Our watch.", "Clarity builds confidence."). Avoid generic corporate slogans and buzzword soup.

## Image, mockup and color direction

Images should feel art-directed: cinematic mountains, dusk skies, halftone clouds, dark product closeups, moody architecture, textured paper. Avoid generic stock people, random offices, cliché robot imagery.

Mockups should be minimal and believable: browser chrome, URL bar, terminal window, command prompt, app icon, phone crop, card stack, badge, seal, UI chips, dashboard fragment, input bar, product label. Avoid full fake dashboards, cheap glossy mockups, device overload.

Color discipline: one dominant palette (base + primary accent + secondary accent + neutrals). Accents must repeat across panels; no random rainbow unless requested; one accent can carry the entire system.

## Anti-generic rules

Never make: random floating icons, generic startup gradients, overdesigned logos, meaningless blobs, messy collages, fake tiny UI, inconsistent logo marks, too many colors, cheap neon, stock-template boards, corporate PowerPoint slides, soulless SaaS dashboards. Use the amount of expression, detail and restraint the brand direction calls for.

## Reference usage

When the user provides references, extract layout rhythm, grid style, spacing, type scale, visual density, logo placement, amount of text, image treatment, accent color logic and system behavior. Do not copy exact logos, names, compositions, slogans or unique assets. References are quality training, not templates.
