# Intake Triage

Use this branch when a request mixes exploration, planning, testing, execution, or handoff and the next useful mode is unclear.

1. Read the closest source and identify the current artifact, approval state, blockers, and evidence already present.
2. Classify the dominant uncertainty as choice, shared-understanding, dependency, high-risk assumption, approved slice, repeated structural friction, or fresh-task continuity.
3. Choose one primary route and name the evidence that made it primary.
4. Treat every later phase as gated. Triage does not authorize execution or external changes.

If two routes remain equally plausible after source inspection, ask one focused question about the earliest dependency.
