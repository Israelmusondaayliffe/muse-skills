# Integration Waves

Run an integration wave after major work waves and before verification.

Re-test only changed or affected surfaces. Do not repeat checks for unchanged surfaces merely because a new wave completed.

Inspect the complete project for:

- contradictions and duplicated work;
- terminology and assumption drift;
- incompatible formats or dependencies;
- uneven evidence standards;
- disconnected or conflicting recommendations;
- narrative, visual, strategic, operational, and technical incoherence.

The integration agent receives fresh context. It may make bounded coherence repairs only when it does not change a workstream's accepted substance. Material repairs return to the owning workstream and require a new critic.

Individually passed workstreams do not imply an integrated pass. One fresh integrated critic may cover several low-risk workstreams in the wave.
