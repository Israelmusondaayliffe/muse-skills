# Session Handoffs

Continuity is maintained eagerly. Update canonical state after every material decision, artifact change, critic verdict, integration wave, approval, or blocker.

A handoff contains operational truth:

- objective, approved plan, state, completed work, changed artifacts, evidence, decisions, assumptions, risks, blockers, open findings, exact next actions, read-first files, commands, and prohibited repetition.

Exclude transcripts, private reasoning, stale plans, copied artifacts, and self-congratulation.

Validate the handoff with a new agent that receives only `project.md`, `handoff.md`, and the artifact register. It must explain the goal, completed work, remaining work, next action, binding decisions, evidence, prohibited repetition, and uncertainty.

Resume requires explicit invocation in the new task.
