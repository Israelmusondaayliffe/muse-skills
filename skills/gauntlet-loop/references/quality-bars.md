# Quality Bars

Select the strongest inspectable standard available:

1. objective tests or measurable requirements;
2. real reference artifacts;
3. primary-source evidence;
4. approved benchmarks;
5. user or stakeholder scenarios;
6. rubrics anchored by concrete examples;
7. structured expert judgment;
8. checklists when stronger methods are unavailable.

Every bar defines:

- dimension;
- artifact and version;
- method;
- pass condition;
- required evidence;
- evaluator role;
- inability-to-evaluate condition;
- remaining-gap format.

Use factual, coverage, analytical, strategic, editorial, creative, technical, operational, and integration dimensions only when applicable. An adjective such as excellent or comprehensive is not a bar.
