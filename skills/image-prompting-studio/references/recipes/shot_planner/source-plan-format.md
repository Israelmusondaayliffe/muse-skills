# Original shot-plan format

Use this compact format instead of the full shot-list template when useful. Original count and pass/fail wording are example values; review against the requested coverage.

```
SHOT PLAN:
Frame 1: [Framing] + [Angle] + [Action] + [Narrative moment]
Frame 2: [Framing] + [Angle] + [Action] + [Narrative moment]
...
Frame 10: [Framing] + [Angle] + [Action] + [Narrative moment]

Coverage verification: [pass/fail with notes]
Collection DNA locked: [yes/no, with locked elements listed]
```
