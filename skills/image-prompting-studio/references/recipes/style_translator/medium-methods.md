# Medium and style methods

## Read the reference first

Identify what makes the depicted character, object or world recognizable, then what makes the target style recognizable. Assign roles if there are several references. A style reference may govern line, palette, shape simplification, texture and composition without replacing the content reference's identity. Discuss conflicting roles only when they would materially derail the result.

Preserve meaningful proportions, fictional premises and visual exaggeration. A physical-looking treatment can depict a stylized or impossible world; realism does not require removing its defining premise.

## Fourteen treatment families

| Family | Useful vocabulary and decisions |
|---|---|
| Traditional painting | Oil, watercolor, acrylic, gouache, fresco; impasto, wash, opaque shapes, visible brushwork, canvas or wall support |
| Drawing/sketch | Charcoal, graphite, ink, conte crayon; contour, hatching, dry marks, paper tooth, line weight |
| Print technique | Woodblock, linocut, screen print, etching, lithograph; carved edges, ink coverage, registration, press impression |
| Digital render | 3D, CGI, isometric, stylized feature animation, real-time render; shader, surface finish, lighting and shape language |
| Animation | Anime, hand-drawn cartoon, stop-motion, cel shading; contour, shape simplification, limited values, constructed materials |
| Photographic era | Daguerreotype, tintype, Polaroid, 35mm film, Kodachrome, disposable camera; grain, flash, color response, exposure and borders |
| Cultural/design aesthetic | Ukiyo-e, Persian miniature, Art Nouveau, Bauhaus, Constructivism, wabi-sabi; use the actual supplied reference and specific visual conventions |
| Material/sculptural | Marble, bronze, ceramic, paper cutout, fabric collage, mosaic; mass, joins, surface response, negative space |
| Graphic design | Poster, cover, book illustration, editorial layout, Swiss International Style; hierarchy, type/image relationships, grids and white space |
| Cinema/narrative | Film noir and named cinematic treatments; lighting, framing, palette and atmosphere that actually characterize the reference |
| Street/urban | Graffiti, stencil, wheatpaste, mural, tags; wall interaction, overspray, layers and weathering |
| Textile/craft | Embroidery, tapestry, quilting, weaving, knitting, cross-stitch; stitch direction, fiber, seams and tactile relief |
| Mixed media | Collage, assemblage, scrapbook, torn paper, layered materials; believable joins, edges and interactions |
| Experimental | Glitch, datamosh, abstraction, double exposure, solarization, infrared; state the desired visual behavior rather than using a generic quality label |

These are a bank, not mandatory output slots. A specific artist or named aesthetic can be translated into visible techniques when useful, without inventing attribution or claiming imitation is exact.

## Faithful translation and reinterpretation

A faithful treatment keeps the defining subject, pose, arrangement and world while changing marks/materials/rendering. Painted contour-following brushwork, woodcut line economy or sculptural mass can make the medium convincing without restaging.

A creative reinterpretation may adjust viewpoint, pose, framing or context to suit the requested artwork. The original source's anti-paste method is useful here: pair the target treatment with a purposeful spatial idea. It is an option, not a universal test of authenticity. Do not reject a faithful same-pose conversion as a filter merely because its composition remains intact.

## Camera-era simulation

Specify the visible treatment: grain structure, flash-to-ambient balance, color drift, halation, edge softness, border, paper or plate surface. Distinguish the camera process from the period depicted. A Polaroid look does not automatically relocate the scene into an earlier decade. Optical and film terms are prompt vocabulary, not proof that a physical camera captured the result.

## Working prompt

```text
Using the supplied [content reference description] as the content anchor and [style reference description, when supplied] for the treatment, render [subject or world] in [precise target medium]. Preserve [recognizable forms, proportions, palette relationships, key details and mood]. Translate [source visual features] into [target mark-making, material response, edge treatment and depth]. [Keep the composition / develop the requested new composition]. [Output form and ratio].
```

If choosing alternatives, name the meaningful differences. A painting, ceramic sculpture and printed poster should differ through medium-specific decisions, not only a changed style word.
