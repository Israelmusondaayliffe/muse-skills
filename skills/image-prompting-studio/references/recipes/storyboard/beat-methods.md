# Story and instructional beats

A beat bank offers establishing view, character introduction, action, reaction, reveal, escalation, reversal, climax, resolution and transition. An instructional sequence instead needs setup/materials, action, visible result and the next usable state. Select the beats that tell this story; no compulsory beat count.

Separate core frames from alternative takes. Each core frame advances time or understanding. An alternative explores a different framing of the same beat and must not accidentally become an extra story event. Track props, screen direction, environment and emotional state between frames.

Use a panel inventory with image/page number, action, framing, dialogue, continuity note and transition only where helpful. Comics can combine several panels on one page; separately generated story frames need identity anchors repeated. Finish when the requested sequence is complete and its output form is unambiguous.
