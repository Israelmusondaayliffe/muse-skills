# Original modernization template

Use for modernization when requested. Decide whether the user wants a modern photographic treatment, an updated world, or both. Keep or change wardrobe/technology according to that choice; the original bundled changes are one example.

## Historical Modernization (source block 12)

```
Using the uploaded historical photograph of [description], recreate as if photographed today with [modern camera]. Maintain [pose, composition, mood] but update [fashion, technology, color processing]. Do not change aspect ratio.
```
