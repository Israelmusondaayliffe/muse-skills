# Preserved layout forms

Use the inventory and positional forms when useful. The original diversity assignment is an optional ten-approach exploration example; its count, labels and checklist do not override the brief. Replace [AR] with the requested ratio or omit it when unnecessary.

## Enforcement (source block 1)

```
DIVERSITY ASSIGNMENT:
1. [Compositional Approach] — SAFE
2. [Compositional Approach] — INVENTIVE
...
10. [Compositional Approach] — EXPERIMENTAL

10 different approaches? ✓/✗
```
