# Reference composition methods

Reference roles: identity, pose/structure, style, scene/background, outfit, object, lighting, color/palette. Specify exactly which roles are transferred and their priority. A style reference should not overwrite identity. A layout reference should guide placement without importing unwanted objects.

Useful combinations include subject plus environment; two subjects interacting; subject plus wardrobe; product plus lifestyle; subject plus style; object plus material; scene plus lighting; arrangement plus new objects; character plus pose; several products in one still life; multiple places into an intentional imagined world; and palette plus subject. Choose what the request needs.

For a believable fusion resolve shared perspective, relative scale, grounding, occlusion, contact, light direction/color and reflections. For intentionally surreal collage, preserve the desired seams rather than enforcing photographic seamlessness. Check each reference's contribution and unintended transfer.
