# Midjourney edit failure recovery
The original worked prompts are preserved, including their historical `--v 8.2` flags. These are craft examples, not a required model choice. Use only selected-model controls in a new prompt.


Diagnose the rendered output, not the prompt alone.

Identify one primary failure class before rewriting. Change the smallest failed dimension first. Do not rerun the identical prompt repeatedly and hope the model changes strategy.

# 1. Identity drift

Symptoms:

- face shape changes;
- hair or skin tone changes;
- body proportions normalize;
- wardrobe details mutate;
- subject becomes a different person;
- identity holds in one image but collapses after relocation.

Likely causes:

- pose, viewpoint, environment, and style changed in one pass;
- too many competing references;
- vague identity anchors;
- strong Personalization, Moodboard, Style Reference, Stylize, or creative controls;
- the subject reference contains inconsistent views or occlusions.

Repair:

1. Separate pose from environment.
2. Use one subject reference or a combined character sheet.
3. Name visible face, hair, body, wardrobe, and accessory anchors.
4. Add `--raw`.
5. Remove nonessential aesthetic controls.
6. Use the strongest intermediate output as the next base.
7. Change only one identity-threatening axis per pass.

# 2. Style bleed or texture mismatch

Symptoms:

- new object looks photoreal in an illustration;
- line weight differs;
- added area has different grain or contrast;
- background and subject look generated by different models;
- inserted element uses a different palette or material response.

Likely causes:

- source medium was not stated;
- V8.2's default aesthetic filled the new area;
- a competing Style Reference, Moodboard, or Personalization profile is active;
- the source reference carries content but not enough style information.

Repair:

1. Restate the source medium and rendering cues.
2. Use the source as a Style Reference when preserving its look.
3. Match grain, line weight, palette, contrast, light direction, and material response.
4. Remove or reduce competing style controls.
5. Run a dedicated cohesion pass after content is correct.

# 3. Object floats or looks pasted

Symptoms:

- no contact shadow;
- wrong scale;
- incorrect perspective;
- weak occlusion;
- object sits above or inside the surface;
- reflections ignore the object.

Repair:

1. State the exact location and size relationship.
2. Add contact, occlusion, cast shadow, reflection, and perspective cues.
3. Use a targeted Editor mask.
4. Use Editor layers when placement must be more exact.
5. Edit one object at a time.

# 4. Wrong count or placement

Symptoms:

- requested three objects become two or four;
- objects appear outside selected regions;
- several masks receive mismatched content;
- frame-left and frame-right are reversed.

Repair:

1. Identify each location separately.
2. Use `frame left`, `frame right`, `upper center`, and similar image-plane directions.
3. Distinguish viewer direction from subject anatomy.
4. Select and edit one region per pass.
5. Avoid asking one prompt to map several objects to several masks.
6. Inspect count before continuing.

# 5. Features mix between references

Symptoms:

- one character receives another character's hair or clothing;
- garment details transfer to the wrong subject;
- product geometry merges;
- environment elements become part of the subject.

Repair:

1. Name each source by visible traits.
2. State which attributes come from each reference.
3. Add `do not exchange facial features, hair, clothing, accessories, or object geometry`.
4. Reduce the number of references.
5. Combine related characters into one clearly separated reference sheet.
6. Solve content before adding style references.

# 6. Prompt is ignored

Symptoms:

- requested edit does not happen;
- the model broadly regenerates the image;
- decorative style language dominates the delta;
- exclusions are ignored.

Repair:

1. Shorten the prompt to the delta.
2. Lead with the direct verb and target.
3. Remove decorative style language.
4. Add `--raw`.
5. Remove conflicting parameters and defaults.
6. Make one change per pass.
7. Use a local mask when the change is spatially precise.

# 7. Too much changes

Symptoms:

- face, wardrobe, crop, or light changes during a prop edit;
- background replacement changes the subject;
- local cleanup causes a full-scene redesign.

Repair:

1. Use `change only` and name the protected regions.
2. Use the full Editor with a targeted mask.
3. Remove unnecessary full-scene description.
4. Preserve crop, camera distance, subject scale, and lighting explicitly.
5. Use the original image as the next base instead of a broad re-generation.

# 8. Aspect-ratio deformation

Symptoms:

- stretched face or body;
- subject becomes wider or taller;
- source is cropped or recentered;
- camera scale changes;
- background is duplicated instead of extended.

Repair:

1. Use the web Editor's resize and canvas tools.
2. State which sides gain content.
3. Preserve original scale, proportions, position, and camera perspective.
4. State no stretch, squeeze, crop, enlargement, or recentering.
5. Make the ratio change in smaller steps.
6. Inspect after each expansion.

# 9. Pose or action deformation

Symptoms:

- anatomy breaks;
- limbs merge;
- garment construction collapses;
- head turn changes identity;
- action becomes different from the request.

Repair:

1. Reduce the angle or motion change.
2. Change gaze, head, torso, and limbs in separate passes when needed.
3. Preserve anatomy and garment construction explicitly.
4. Solve pose before changing environment or style.
5. Use a reference that clearly shows the desired action when available.

# 10. Environment replacement looks composited

Symptoms:

- subject light does not match;
- edge halo;
- wrong atmospheric depth;
- background perspective conflicts;
- subject appears cut out.

Choose one intention:

## Background-only replacement

Preserve subject lighting and state that the change is a background plate swap.

## Fully integrated relocation

Relight the subject to match the new environment.

Do not request both at once unless a hybrid look is intentional.

Repair cues:

- light direction;
- color temperature;
- reflected light;
- edge softness;
- atmospheric depth;
- lens behavior;
- grain;
- perspective.

# 11. Text changes unintentionally

Symptoms:

- existing text mutates;
- new text is misspelled;
- extra lettering appears;
- hierarchy or alignment changes.

Repair:

1. Quote the exact text to keep or replace.
2. Name every text region that must remain.
3. Use a local mask.
4. State no additional text.
5. Inspect spelling, hierarchy, alignment, and accidental marks.

Do not certify production typography from prompt intent alone.

# 12. Product or logo geometry drifts

Symptoms:

- logo shape changes;
- controls move;
- product proportions change;
- material and geometry are redesigned together.

Repair:

1. Separate geometry from style.
2. Name silhouette, proportions, control layout, logo placement, and material finish.
3. Use one strong product reference.
4. Add `--raw`.
5. Use a local mask for the edited region.
6. Apply retexture only after geometry is approved.

# 13. Architecture drifts

Symptoms:

- window rhythm changes;
- openings disappear;
- massing changes;
- facade pattern mutates;
- camera position shifts.

Repair:

1. Name massing, facade geometry, window rhythm, openings, and camera position.
2. Change one material or environmental axis at a time.
3. Use the original as the base and, when needed, as a Style Reference.
4. Use targeted masks for facade zones.
5. Separate outpainting from retexturing.

# Diagnostic output format

When the user asks why an edit failed, respond in this order:

1. Primary failure.
2. Evidence visible in the result.
3. Likely competing control or missing anchor.
4. Smallest corrective action.
5. Revised prompt.
6. Staged fallback, only when needed.

Keep the diagnosis specific. Do not list every theoretical cause when one cause is visibly dominant.

# Verification checklist

Compare the output against the source and request.

Check:

- requested delta is present;
- protected identity anchors;
- body proportions and anatomy;
- product or architectural geometry;
- wardrobe and accessories;
- object count and placement;
- contact, shadow, reflection, and occlusion;
- camera position and perspective;
- source style or requested new style;
- aspect ratio and source proportions;
- text spelling and layout;
- unintended objects;
- reference feature swapping.

Only continue to the next pass after the current pass is acceptable on its own.
