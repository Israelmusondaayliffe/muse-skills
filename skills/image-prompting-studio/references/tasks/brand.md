# Task: Brand interpretation (brand visual language)

Scope: translate supplied or researched brand visual language into image prompts — branded products, mockups, identity treatments, creative recontextualization. No brand-strategy tool is required.

Read first: `../prompt-contract.md`. When a model is named, consult only its entry in `../model-profiles.md`.

## Workflow

1. Work directly from the named brand and supplied references. Extract observable color, materials, patterns, mark/letterform character and design language. Verify factual brand claims when needed. Distinguish proposed speculative concepts from products the brand actually makes.
2. Map the design intent to the use case before exploring: branded product, logo treatment, packaging, mockup, apparel, poster, icon or typography. For a focused request, develop it directly. For open exploration, compare direct, adjacent, lateral and wild-card concepts — no mandatory funnel, no picking a final creative winner for the user.
3. Preserve the creative tension of transferring recognizable design language into a new object or context. Make material and construction plausible for the intended medium. A sparse dark identity board, white studio product card or metallic mark is an optional treatment, not a universal aesthetic.
4. Keep exact marks/copy and source facts distinct from creative invention. A generated mark is not guaranteed production-perfect. Let the user choose which results become preferred references.

Read as needed: `../libraries/brand-design-catalog.md`, `../libraries/brand-dna-extraction.md`, `../libraries/creative-directions-brand.md`, `../recipes/brand_interpretation/brand-patterns.md`, and the preserved concept recipes in `../recipes/brand_interpretation/nano-brand.md`. For an identity overview image, the optional `identity-board-recipe.md` holds the brandkit layout — choose its treatment only when it fits; a dark sparse board is one option, not a fixed aesthetic. Use `../libraries/reference-deconstruction.md` to derive a transferable visual system when requested.
