# Task: Layout architect (spatial arrangement)

Scope: prompts for spatial arrangement, relative scale, panels and element relationships — when placement is the main problem in a scene, still life, grid or designed composition.

Read first: `../prompt-contract.md`. When a model is named, consult only its entry in `../model-profiles.md`.

## Workflow

1. Make the arrangement explicit enough to guide the image: what belongs where, what overlaps, what dominates, how the eye moves through it.
2. Inventory the required elements and exact text. Distinguish fixed positions from areas open to exploration. Establish the canvas, relative scale, foreground/midground/background, adjacency, overlap and intended hierarchy. Use a supplied layout reference as the authority for its assigned role.
3. Read `../recipes/layout_architect/layout-methods.md` for spatial language, composition options and task-specific treatment, and `source-layout-templates.md` for the preserved element inventory and positional prompt forms.
4. Write a complete prompt in the requested form. When no count is supplied, choose a useful amount of work for the brief; do not force ten compositions. For alternatives, preserve required content and explore arrangement only where allowed. Interpret percentages and coordinates as design intent unless the destination surface exposes an actual placement control.
5. Check that required elements appear once in their intended roles, directions and scale are consistent, text is exact, and a composite grid is not confused with separate files. Do not promise pixel-perfect placement from prose. A factual diagram also needs correct facts and relationships; a beautiful layout does not verify them.

Deliver the prompt(s) with only the layout assumptions necessary to use them. If images are supplied for review, compare actual placement against the brief and describe material differences.
