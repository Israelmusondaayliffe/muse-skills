# Task: Series (coherent image sets)

Scope: prompts for a coherent series of images with a recurring character, product, place or visual identity.

Read first: `../prompt-contract.md`. When a model is named, consult only its entry in `../model-profiles.md`.

## Workflow

1. Define the recurring anchor and the meaningful variation across the set. Identity can be face/hair/body, product silhouette and construction, a place's spatial features, or a coherent design language. Separate core identity from attributes the brief deliberately changes (wardrobe, pose, material, time).
2. Choose a delivery form from the request: independently copyable frame prompts, a shared session brief with frame directions, or one prompt requesting a complete set. State which form is being delivered. Consistency is the primary craft; the number of prompt blocks is not the number of generated files. A contact sheet is one composite image, not multiple files.
3. For a coherent photoshoot: preserve wardrobe rules, color treatment, environment and physical light source as needed, while letting camera, action, expression and visible lighting develop naturally. For products: keep construction and proportions comparable. Each frame needs a reason to exist beyond cosmetic wording changes.
4. If outputs are independent prompts, repeat the essential shared anchors accurately. If one batch prompt is requested, keep the common anchors together and enumerate each image. Do not promise perfect continuity or impose an obsolete eight-image ceiling across all models.
