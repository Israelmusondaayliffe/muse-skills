# Task: Editorial (posters, covers, pages)

Scope: prompts for posters, covers, spreads, campaign key visuals and page compositions combining imagery and typography.

Read first: `../prompt-contract.md`. When a model is named, consult only its entry in `../model-profiles.md`.

## Workflow

1. Define the page's communication job, format, audience and visual hierarchy. Gather exact copy, supplied images, desired design tradition and palette.
2. Compose image and typography together: focal point, headline scale, negative space, supporting copy, margins, alignment, and the device that makes the page recognizable.
3. Use a reference's observable design language without requiring a preliminary brand board. The [reference deconstruction](../libraries/reference-deconstruction.md) identifies idea/tension, color/material, typography, composition, visual device, grid and application logic — turn that into the requested page; produce a separate board only when requested.
4. Design traditions are starting vocabulary, not generic labels: describe how their scale, rhythm, texture and layout apply to this content.
5. Distinguish a single page or spread from a set of separate pages. Prompts for an image of a UI or slide are visual assets, not working interfaces or editable presentation files.

NL preserves connected art direction; JSON can help exact copy and reference separation. Check the copy inventory, hierarchy and format before delivery; assess actual legibility only after viewing a render.
