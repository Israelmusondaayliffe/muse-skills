# Task: Campaign grid (composite moodboard)

Scope: prompts for one composite campaign grid or moodboard with distinct cells and coherent visual DNA.

Read first: `../prompt-contract.md`. When a model is named, consult only its entry in `../model-profiles.md`.

## Workflow

1. The output is a single composite grid. Define rows/columns, reading rhythm and intended use, then give every cell a specific role.
2. Keep product/character recognition and the campaign's color/material language coherent while varying context, scale, framing and narrative emphasis where the brief allows.
3. Extract visible identity and recognition anchors from the reference. Separate the subject's physical form from its narrative associations. A product can be a hero, a macro material detail, an environmental clue or a partly occluded element. Do not force luxury spaces, fashion subjects or extreme diversity onto every campaign.
4. Use a balanced concept bank: hero still life, macro, interaction, environmental scene, abstract material, lived activity, architectural geometry, type-led cell, atmospheric detail. Keep intentional repetition when it builds rhythm. State each cell's content and any shared border/gutter/background rules. Specify exact text if present.

Read `../recipes/campaign_grid/campaign-grid.md` for methods and recipes. Do not promise the model will always return the requested cell count. If an output exists, inspect cell count, repetition and visual DNA; do not label this composite as separate-image delivery.
