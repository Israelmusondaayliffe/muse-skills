# Task: Storyboard (narrative panels)

Scope: prompts for comics, storyboards, narrative panels and illustrated instructions with ordered beats and continuity.

Read first: `../prompt-contract.md`. When a model is named, consult only its entry in `../model-profiles.md`.

## Workflow

1. Identify the story or instructional progression, recurring characters/objects, key beats and reading order. Decide whether the deliverable is one page of panels, separate frames, or several pages — declare this explicitly so a multi-panel comic is not confused with multiple image files.
2. Create a compact character/world anchor. Give each panel a job: establish, act, react, reveal, transition, resolve. Carry props, screen direction, wardrobe and environmental continuity intentionally. Use close-ups and inserts when they serve the story; a protagonist need not appear in every frame. Separate essential beats from optional alternative takes.
3. Specify per-panel action, framing, emotional change, spatial relationship, dialogue and sound-effect lettering when requested. Keep exact dialogue quoted, bubbles tied to the right speaker. Instructional steps must be physically possible and correctly ordered. Dense choreography needs clear causal beats, not a generic action pose.

A shared system-style prompt can hold continuity, but enumerate panels inside a page separately from separate image outputs. This task delivers still-image prompts only.
